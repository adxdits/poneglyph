## Why "Poneglyph"

In *One Piece*, poneglyphs are indestructible stone tablets carved in a lost script — the truth is
right there on the stone, but almost no one alive can read it. Ghidra's decompiler output is a lot
like that: technically text, technically C-shaped, but carved in a dialect only the decompiler
understands. This tool plays translator, turning that pseudo-code into clean, human-readable C —
and then proves the translation is faithful by compiling it and running generated tests before
handing you the verdict.
